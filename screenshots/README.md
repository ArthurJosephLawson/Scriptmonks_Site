# LONEWOLF screenshots

Drop LONEWOLF screenshots here. Filenames become captions; a leading number sets the order (e.g. `01 dashboard.png`).

Then run `pnpm dev` (or `pnpm build`) — `scripts/sync-screenshots.mjs` copies them to `public/screenshots/lonewolf/` and regenerates `src/data/screenshots.generated.ts`.

Before adding screenshots, blur or crop any personal data.
